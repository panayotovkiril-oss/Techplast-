# TechPlast КАЛИБЪР — инсталиращ се PWA вариант

Това е самостоятелен PWA пакет: `index.html`, `manifest.webmanifest`, `service-worker.js` и икона. Не използва външни библиотеки, CDN или мрежови API.

## Публикуване

1. Качете **цялото съдържание на тази папка** на един и същ HTTPS адрес (например `https://example.com/kalibar/`). Не отваряйте `index.html` от Downloads/Files — това е `file://` и не може да се инсталира.
2. Отворете адреса веднъж с Chrome на Android, докато има интернет. Service worker ще кешира приложението.
3. При изпълнени условия браузърът показва бутона „Инсталирай приложението“. Натиснете го и потвърдете системния диалог.

След първото отваряне приложението работи офлайн. Инсталирането винаги изисква действие на потребителя — браузър не позволява автоматична инсталация при сваляне на файл.

## Локална проверка

`file://` не е подходящ за PWA. За проба на компютър стартирайте localhost сървър от тази папка; за реална инсталация на Android използвайте HTTPS. Само поставянето на файловете в телефона не е достатъчно.
